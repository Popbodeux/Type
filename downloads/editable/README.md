# Editable Type project

Download **Type-Editable.zip**, extract the whole ZIP, then import `Type-Space-Dash/project.godot` in **Godot 4.6.3 stable**. Press F5 to play. This is the complete editable v0.4.3 project with scripts, scenes, assets, import settings and tests.

The newly supplied player model is **not included or integrated**; this package uses the existing placeholder. Grass appearance is still under review. This reconstruction is not an exact source port. Windows execution has not been tested here. See `OPEN-FIRST.txt`, `README.md` and `VALIDATION.md` in the ZIP for controls, setup and limits.
